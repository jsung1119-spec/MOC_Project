# 작업명 입력과 검토/승인 상세 보기

## 목적

새 변경 판단을 시작하는 사람이 작업을 알아보기 쉬운 이름으로 직접 입력하고, 그 이름을 MOC 이력이 보이는 모든 메뉴에서 일관되게 확인하게 한다. 검토/승인자는 작업명을 선택해 판단 근거와 질문 답변을 검토한다.

## 사용자 흐름

1. 사용자가 새 변경 판단을 선택한다.
2. 변경 항목 선택 화면에서 `작업명`을 직접 입력한다.
3. 작업명과 변경 항목을 모두 선택해야 다음 단계로 이동할 수 있다.
4. 시스템은 새 MOC 건의 `title`에 입력한 작업명을 저장한다.
5. 대시보드, 작성 이력, Reminder, 검토/승인, 진행 상태와 문서 미리보기는 같은 `title`을 표시한다.
6. 검토/승인 목록에서 작업명을 선택하면 작업 상세 화면이 열리고, 기본 정보·판단 결과·전체 질문과 답변을 보여 준다.

## 화면 변경

- 새 변경 판단 화면의 안내 문구 아래에 필수 `작업명` 입력란을 추가한다.
- 안내 문구는 `작업 내용을 알아보기 쉬운 이름으로 입력해 주세요.`로 표시한다.
- 작업명이 비어 있으면 다음 단계 버튼을 비활성화한다.
- 검토/승인 메뉴의 숫자 배지는 Reminder 배지와 동일한 `em` 요소와 기존 스타일을 재사용한다.
- 검토/승인 목록의 작업명은 버튼으로 표시한다.
- 상세 화면은 해당 작업의 작업명, 관리번호, 작업 유형, 작성자, 대상 여부, 등급, 위험도, 판단 근거, 질문과 답변을 보여 준다.

## 범위와 예외

- 기존 이력의 작업명은 변경하지 않는다.
- 작업명은 선택 사업장에 생성되는 새 MOC 건에만 저장한다.
- 작업명 상세 보기에서 승인 처리는 하지 않으며, 목록으로 돌아가서 기존 승인하기 버튼을 사용한다.
- 대기 건수 계산과 사업장별 필터는 기존 동작을 유지한다.

## 검증

- 작업명이 비어 있으면 다음 단계로 이동할 수 없는지 확인한다.
- 입력한 작업명이 새 건의 `title`로 생성되는지 확인한다.
- 대시보드와 작성 이력에서 동일한 작업명이 표시되는지 확인한다.
- 검토/승인 배지가 Reminder와 같은 태그와 스타일을 사용하는지 확인한다.
- 검토/승인 목록의 작업명을 누르면 질문과 답변이 있는 상세가 열리는지 확인한다.
