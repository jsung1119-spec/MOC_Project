# Vercel 공개 시연판 설계

## 목적

코치가 링크만으로 SafeChange PSM 변경요소관리 MVP의 화면과 핵심 흐름을 확인할 수 있는 공개 Vercel 주소를 제공한다. 실제 운영용 데이터베이스와 이메일 연동은 이번 범위에서 제외한다.

## 사용자 경험

- Vercel 주소 접속 후 `입장` 버튼과 사업장 선택부터 시작한다.
- 대시보드, 새 변경 판단, 질문 응답, 판단 결과, 작성 이력, 검토/승인 화면은 현재 ChatGPT 배포본과 같은 화면으로 제공한다.
- 작성 이력과 선택 상태는 접속자의 브라우저에만 저장된다. 다른 브라우저나 다른 사용자는 독립된 시연 상태로 시작한다.
- 링크를 가진 누구나 접속할 수 있는 공개 Vercel 주소로 배포한다.

## 구조

- GitHub `main` 브랜치를 공통 화면 소스로 유지한다.
- ChatGPT 사이트는 기존 `npm run build`의 Cloudflare/vinext 빌드를 계속 사용한다.
- Vercel은 `vercel.json`에서 별도 Vercel 시연 빌드 명령을 사용한다. 따라서 공통 화면 코드를 복제하지 않는다.
- Vercel의 `/api/health/db`는 Cloudflare D1에 연결하지 않고 `demo` 상태를 반환한다. 이 API는 시연 환경에서 DB를 요구하지 않음을 명확히 표시한다.
- UI 수정은 `main`에 반영한 뒤 Vercel은 GitHub 연동으로 자동 배포되고, ChatGPT 사이트는 동일한 소스로 별도 배포한다.

## 범위 밖

- Vercel용 데이터베이스 이전 및 서버 저장
- 실제 이메일 Reminder 발송
- 사내 인증, 사용자별 권한, 파일 첨부 저장
- 기존 ChatGPT 사이트의 접근 권한 변경

## 검증 기준

- 기존 판단 엔진 테스트가 통과한다.
- Cloudflare용 기존 빌드가 통과한다.
- Vercel 시연 빌드가 통과한다.
- Vercel 배포 뒤 홈페이지가 사업장 미선택 상태로 열리고, 화면 흐름을 사용할 수 있다.
