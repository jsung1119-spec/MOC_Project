# 포스코퓨처엠 CI 적용 설계

## 목적

SafeChange의 기존 방패형 심볼과 영문 브랜드명을 포스코퓨처엠 국문 CI로 교체한다.

## 적용 범위

- 입장 화면의 브랜드 영역
- 입장 후 좌측 상단 사이드바 브랜드 영역

## 구현 방식

- 제공된 PNG 파일을 `public` 폴더에 서비스용 자산으로 추가한다.
- 브랜드 마크와 SafeChange 텍스트를 하나의 이미지로 교체한다.
- 이미지 비율을 유지하고 사이드바 폭 안에서 세로 크기를 제한한다.
- 모바일에서는 CI가 작게 보이되 사업장 선택 메뉴를 침범하지 않도록 한다.

## 제외 범위

- 색상 테마, 사업장 선택, 메뉴 구조, 업무 데이터는 변경하지 않는다.
