# 등급 확정 후 검토/승인 배지 표시

## 목적

새 변경 판단에서 등급을 확정한 사용자가 판단 결과를 먼저 확인할 수 있도록 자동 화면 이동을 제거한다. 동시에 사업장별 검토/승인 대기 건수를 좌측 메뉴에서 즉시 확인할 수 있게 한다.

## 사용자 흐름

1. 사용자가 답변 검토 화면에서 최종 판단을 실행한다.
2. 시스템은 판단 결과와 함께 해당 건의 상태를 `JUDGMENT_COMPLETED`(판단 완료)로 저장한다.
3. 화면은 판단 결과 화면을 유지한다. 검토/승인 메뉴로 자동 전환하지 않는다.
4. 사용자가 필요할 때 좌측 검토/승인 메뉴를 선택한다.
5. 검토/승인 메뉴는 현재 선택한 사업장의 판단 완료·제출·검토 중 건 가운데 아직 승인되지 않은 건수를 배지로 표시한다.

## 화면 변경

- `검토/승인` 좌측 메뉴 항목 우측에 작은 숫자 배지를 표시한다.
- 배지는 대기 건수가 0이면 숨긴다.
- 검토/승인 화면은 판단 완료 건도 승인 대상 목록에 표시한다.
- 기존 `승인하기` 버튼을 누르면 해당 건은 승인 완료 상태가 된다.

## 범위와 예외

- 배지와 목록은 선택한 사업장(`site`)의 이력만 계산한다.
- 이미 승인 완료 또는 종결된 건은 배지와 승인 대기 목록에서 제외한다.
- 문서 작성 여부는 배지 표시 조건이 아니다. 등급 확정 직후부터 포함한다.

## 검증

- 판단 실행 뒤 현재 화면이 결과 화면으로 유지되는지 확인한다.
- 판단 완료 건이 검토/승인 메뉴 배지와 승인 목록에 나타나는지 확인한다.
- 사업장을 바꾸면 다른 사업장 건수는 표시되지 않는지 확인한다.
- 승인 처리 뒤 배지 수가 감소하는지 확인한다.
