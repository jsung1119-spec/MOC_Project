# 사업장 입장 및 데이터 분리 설계

## 목적

개별 로그인 없이 공장 단위로 SafeChange를 사용한다. 첫 화면의 입장 버튼을 누르면 앱이 열리고, 사용자는 좌측 상단의 사업장 선택 메뉴로 작업 범위를 정한다.

## 화면과 상태

- 첫 화면은 서비스 안내와 `입장` 버튼만 제공한다.
- 입장 후 좌측 상단에 `사업장 선택` 메뉴를 표시한다.
- 사업장 목록은 가나다순으로 `포항라임공장`, `포항화성공장`을 제공한다.
- 선택 사업장은 브라우저에 저장해 새로고침 후에도 유지한다.
- 우측 상단에는 사용자 정보 대신 현재 선택 사업장만 표시한다.

## 데이터 분리

- MOC 건에 `site` 값을 추가한다.
- 대시보드, Reminder, 이력 목록과 상태 통계는 선택 사업장과 일치하는 건만 표시한다.
- 새 MOC 건은 현재 선택 사업장에 자동으로 연결한다.
- 기존 Mock 건은 두 사업장에 나누어 배정한다.

## 오류 처리와 검증

- 사업장을 아직 고르지 않은 경우, 대시보드 대신 선택 안내를 표시한다.
- 기존 사업장 값이 유효하지 않으면 사업장 미선택 상태로 초기화한다.
- 단위 테스트는 사업장 목록의 가나다순 정렬과 선택 사업장 기준 목록 분리를 검증한다.

## 범위 제외

- 실제 사용자 인증, 사업장 관리자 권한, 데이터베이스의 사업장 마스터 테이블은 이번 변경에 포함하지 않는다.
