# Mock 판단 규칙

판단 엔진은 `app/lib/moc.ts`에 화면과 분리되어 있으며 질문 ID와 답변값만 입력받습니다.

| 규칙 | 조건 | 결과 | 근거 |
|---|---|---|---|
| R-001 | 동일 규격=예, 용량·재질·운전·Logic 변경 없음 | 비대상 | 4.1.1 |
| R-002~005 | 용량·재질·운전조건·Logic 중 하나 이상 변경 | MOC 대상, 기본 3등급 | 4.2.x |
| R-006 | 위험도 증가=예 | 최소 2등급, 중간 위험 | 5.1.2 |
| R-007 | 중대한 공정조건/안전설비 변경=예 | 1등급, 높은 위험 | 5.1.3 |
| R-008 | 잘 모르겠음 또는 상충 답변 존재 | 담당자 검토 필요 | 3.3.2 |

## 상충 답변

‘동일 규격’이라고 답하면서 용량·재질·운전조건·Logic 변경을 동시에 선택하면 자동 확정하지 않습니다.

## 실제 지침 전환

1. 업무지침 조항을 `guidelines` 테이블로 이관합니다.
2. 질문과 표시 조건을 `questions` 테이블/관리 화면에서 관리합니다.
3. 규칙 조건과 결과를 `decision_rules.condition_json`, `result_json`에 저장합니다.
4. 승인된 버전만 활성화하고 판단 당시 규칙·조항을 스냅샷으로 `moc_evidences`에 보존합니다.
5. 실제 규칙 전환 전 PSM 담당자 승인과 회귀 테스트를 수행합니다.
