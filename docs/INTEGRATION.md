# 사내 시스템 연계 가이드

## 업무지침

현재 Mock 질문·규칙·조항은 독립 모듈과 DB 테이블로 분리되어 있습니다. 실제 지침 도입 시 관리자 승인, 버전, 시행일을 추가하고 기존 판단에는 당시 버전 스냅샷을 유지합니다.

## 인증과 권한

MVP 테스트 로그인은 화면 데모용입니다. 운영 전 사내 SSO(OIDC/SAML)로 교체하고 서버에서 `USER`, `REVIEWER`, `ADMIN` 권한과 건별 소유권을 검증합니다.

## 메일

메일은 `EMAIL_PROVIDER=log`를 기본값으로 둡니다. 사내 SMTP 또는 메일 API 어댑터를 추가할 때 중복 방지 키를 `mocCaseId + reminderType + scheduledDate`로 사용합니다.

## 문서/설비 시스템

- EDMS: 승인된 신청서 PDF와 첨부파일을 관리번호 기준으로 전송
- ERP/CMMS: 작업오더 번호, 설비번호, 계획일 동기화
- DCS/도면 시스템: P&ID·Logic·Set Point 개정 번호 연결
- 사내 LLM: 규칙 판단은 유지하고, 서술 초안/누락 점검만 Provider 인터페이스로 위임

## 운영 전 필수 보강

서버 세션, 비밀번호 salt 해시, 감사 로그, 첨부파일 악성코드 검사, 백업/복구, 개인정보 보유기간, 전자서명, 규칙 변경 이중 승인, 보안 점검을 적용해야 합니다.
