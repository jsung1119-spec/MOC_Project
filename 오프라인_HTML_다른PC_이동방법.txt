SafeChange PSM 변경요소관리 · 다른 PC 이동 방법

1. 기존 PC에서 SafeChange_MOC_시연용_오프라인.html 파일을 엽니다.
2. 우측 상단의 [데이터 백업]을 눌러 JSON 백업 파일을 다운로드합니다.
3. 이 ZIP 파일과 JSON 백업 파일을 USB, 사내 보안 저장소 또는 개인 클라우드로 새 PC에 옮깁니다.
4. 새 PC에서 ZIP 파일의 압축을 풉니다.
5. SafeChange_MOC_시연용_오프라인.html 파일을 더블클릭해 브라우저로 엽니다.
6. 사업장을 선택해 입장한 뒤, 우측 상단 [데이터 복원]을 누릅니다.
7. 기존 PC에서 옮긴 JSON 백업 파일을 선택합니다.

주의
- 이 HTML 시연판의 이력, 질문 기준, Reminder 기록은 브라우저 LocalStorage에 저장됩니다.
- JSON 백업 파일을 다른 사람과 공유하면 시연 데이터도 함께 공유되므로 보관에 유의하세요.
- .env 파일은 오프라인 HTML 실행에는 필요하지 않습니다. Next.js 웹 프로젝트/DB를 실행할 때만 별도 복사가 필요합니다.
